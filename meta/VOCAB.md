# VOCAB — controlled vocabulary

Starter tags for orogeny / thermochronology. Replace the tables if your
field is different. Rules:

- 全小寫、kebab-case、英文。
- 新標籤：先加進本檔（附一行定義），才能用在筆記 frontmatter。
- 同義提案一律映射到本表。

## topics（研究主題）

| tag | definition |
|---|---|
| orogeny | mountain building processes in general |
| taiwan-orogeny | Taiwan arc-continent collision and wedge development |
| thermochronology | cooling ages and thermal history reconstruction |
| erosion-surface-processes | erosion laws, surface processes, landscape evolution (incl. glacial) |
| tectonics-general | plate-scale tectonics not tied to one orogen (incl. transpression, oblique collision) |
| wedge-mechanics | critical taper, accretionary/orogenic wedges, fold-and-thrust belts, décollements |
| exhumation | rock uplift and exhumation pathways/rates |
| crustal-rheology | strength, viscosity, brittle-ductile behavior, fluids/pore pressure, lower-crustal flow |
| geothermics | heat flow, geotherms, thermal structure, heat advection |
| flexure | lithospheric flexure and foreland response |
| foreland-basin | foreland basin stratigraphy and sediment budgets |
| rifting-basins | continental rifting, passive/hyperextended margins, rift & marginal-sea basins |
| metamorphism | metamorphic petrology, peak T conditions, facies |
| seismotectonics | earthquake ruptures, active faults, seismic hazard, paleoseismology |
| volcanism | volcanic activity, hazards, magmatic plumbing systems |

## methods（方法）

| tag | definition |
|---|---|
| numerical-modeling | numerical geodynamic/mechanical modeling (finite element / finite difference) |
| analog-modeling | sandbox / laboratory analog experiments |
| analytical-modeling | closed-form theory (e.g. critical-taper solutions, stretching models) |
| aft | apatite fission-track dating |
| zft | zircon fission-track dating |
| ahe | apatite (U-Th)/He dating |
| zhe | zircon (U-Th)/He dating |
| ar-ar-dating | 40Ar/39Ar and K-Ar dating |
| u-series-dating | U-Th-Ra disequilibrium dating |
| thermal-modeling | thermal-kinematic / thermal-history modeling (Pecube, QTQt, MDD) |
| rscm-thermometry | Raman spectroscopy of carbonaceous material peak-T thermometry |
| isotope-geochemistry | stable/radiogenic isotope analysis incl. C-isotope thermometry |
| provenance-analysis | sediment source tracing (detrital grains, geochemistry) |
| structural-geology | field structural analysis, cross sections, balancing |
| geodesy | GPS/InSAR/leveling deformation measurement & inversion |
| seismology | earthquake source studies, seismicity analysis |
| seismic-tomography | seismic imaging of crustal/mantle structure |
| plate-reconstruction | plate-kinematic reconstruction |
| stratigraphic-forward-modeling | diffusion-based stratigraphic simulation (e.g. Dionisos) |
| synthesis-review | review or data compilation paper |
